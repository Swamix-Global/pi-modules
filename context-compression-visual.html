The actual request path

01 · Route

OpenAI-compatible messages or input. Antigravity bypasses this proxy.

02 · Estimate

Serialized text characters ÷ 3.5, rounded up. Image payloads are excluded; this is not a model tokenizer.

03 · Group

Leading system/developer messages form a fixed prefix. Each user turn includes its replies and tool activity.

04 · Condense

Only above 64k: all older eligible groups launch in parallel. Cache hits avoid model calls.

05 · Forward

Reassemble prefix + notes + newest 2 turns. Check the budget again; see overflow behavior below.

Current code ≠ documented no-drop rule

main.ts:498–511 removes oldest unprotected groups while the result is still over budget. These deletions are recorded as kind: "drop", fallback: true, but still conflict with the project’s “never drop blocks” instruction. Protected turns and fixed fields can still exceed the threshold and are forwarded with a warning. This report describes the code; it does not change it.

Two different caches

SQLite summary cache

Persists condenser output under:

hash(block) + "-" + model + "-" + maxTokens

Same original block, model and output cap → same note. A recognized summary is not summarized again. The cache key does not include the word target or prompt, so changing those alone does not invalidate old entries.

OpenAI upstream prompt cache

Separate from summary reuse. The warmer retains an eligible rendered summary prefix and makes a keepalive after 4½ minutes; threads expire after 15 minutes without real activity. Only eligible OpenAI requests with thread identity participate.
